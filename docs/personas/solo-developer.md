# Persona P1 — Solo Developer

**Description**

A solo developer managing personal projects, side work, or small team tasks. They use TLC to organize their own work, track progress locally, and maintain task state across sessions. This persona cares about ease of use, quick task entry, flexible querying, and ability to sync task state with external systems (GitHub, personal Jira instance).
