# Persona P4 — Test Engineer

**Description**

A test engineer or maintainer responsible for validating TLC functionality, maintaining test coverage, and ensuring system reliability. This persona writes and runs E2E tests, validates user stories, and verifies CLI/API behavior across changes. They care about test coverage, regression prevention, traceability between requirements and tests, and the ability to verify all TLC features through automated testing.
